# Kachna 3310

Nokia, kterou na nočním trhu předělali na kachničku. Fialové peří, tyrkysový zobák a číro, růžové brýle. Dress code, ne návrh.

## Hraní

```bash
python3 -m http.server 4173
```

Otevři `http://127.0.0.1:4173`. Šipky, WASD, tah prstem, nebo tlačítka na přístroji.

Krycí jméno si hra pamatuje v prohlížeči. Jednotka skóre je **kvá** a neskloňuje se.

## Stín

- Synthrohlík dá 10 kvá krát kombo. Kombo začíná na ×1, roste do ×5, dokud svítí meter, a spadne, když meter zhasne.
- Každý čtvrtý rohlík přidá 5 kvá adrenalinu a ulice zrychlí.
- Stín je tvoje nejlepší skóre pod stejným jménem na tomhle přístroji. Cíl je přerůst ho.
- Síň kváknutí je výloha nejlepších jmen v tomhle prohlížeči. Nikam se to neposílá.

Testy pravidel: `npm test`.
